# wiki 知识库

这是一个独立于 `ObNotion` 的知识库，采用“原始资料 → 沉淀池 → 知识”的三层管理方式。

## 入口

- [[管理流程]]：完整的资料处理规则和协作方式
- [[原始资料/README|原始资料]]：你放入新文件的位置
- [[沉淀池/README|沉淀池]]：我整理、提纯后等待你确认的内容
- [[知识/README|知识]]：双方确认后的最终知识

## 使用方式

你只需要把新文件放到 `原始资料/对应主题域/`。我会先阅读并整理简介、核心观点、关键词和关联内容，写入同名主题域的 `沉淀池/`，然后暂停等待你交流确认。确认后，我再把最终版本写入同名主题域的 `知识/`，并补充相关页面的双向链接。

当前主题域：

- `项目/`：完整项目、项目架构、项目源码和项目复盘

主题域只在实际出现资料时创建，不提前建立大量空目录。

`ObNotion` 目录使用原有管理方案，本知识库不修改、不迁移、不混用其中的内容。
